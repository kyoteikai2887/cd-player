# Windows 后台快捷键

适用版本：V1.0.0 Windows 便携版；固定组合自 core.4 沿用。先在播放器中选择专辑或曲目开始播放；之后切换到其他软件、隐藏主窗口或收到托盘，仍能使用以下组合。

| 功能 | 快捷键 |
|---|---|
| 上一首 | Ctrl + Alt + ← |
| 下一首 | Ctrl + Alt + → |
| 播放 / 暂停 | Ctrl + Alt + P |

右键系统托盘中的 CD 播放器图标，选择“快捷键说明”，可以随时查看组合和实际启用状态。托盘菜单也提供上一首、下一首和播放/暂停。

退出播放器会释放快捷键。窗口右上角 × 只会隐藏，后台快捷键继续工作。没有曲目/队列时，请先回到主窗口选歌；本轮不自动选择收藏里的第一张专辑。上一首沿用既有播放规则：当前曲目已播放超过约三秒时先回到本首开头，开头处再按会切到前一首。

如果其他程序已经注册相同组合，本程序不抢占，托盘说明会显示“已被其他程序占用”；此时可用托盘播放菜单。最初尝试的 Ctrl+Alt+空格在本机被占用，最终改用 P。当前为固定组合，自定义绑定和键盘媒体专用键尚未实现；网页预览不支持原生全局键。

实现依据：[Microsoft RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。原生壳通过独立消息线程注册 MOD_NOREPEAT，将三个动作串行交给唯一 main 音频引擎，不为触发快捷键而显示播放器窗口。
