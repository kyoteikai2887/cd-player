# V1.2 新增功能说明

本次为 **1.2.1 正式版**（2026-10-13）。先从旧版托盘选择“退出”，再解压整个新包，运行 CD播放器.exe。已有收藏、设置和 MV 关联沿用；保留 runtime、web、licenses 文件夹。

## 主舞台音乐图案

收藏页主舞台的点阵随正在播放的真实声音起落，下方连线在对应频段同时有声音时亮起。造型取自矩阵和注意力图，显示的是音乐，画面没有模型性能或训练数值。

暂停、静音、零音量和音频分析不可用时，图案回落成静止刻纹。极轻的声音可能低于显示门限。窗口隐藏、离开收藏页或关闭图案时停止采样，不影响音乐继续播放。

在“设置 → 外观 → 主舞台音乐图案”可以关闭它。减少动效时采用更慢、更小的变化，并隐藏峰值格；系统高对比度下隐藏装饰。

音乐图案现在与署名、曲名、统计和按钮同组摆放，随专辑名换行一起移动，宽屏下保持自身比例。专辑名最多显示两行，当前曲名在胶囊内省略；悬停可看完整名称，点按仍可打开详情或正在播放页。较小窗口采用紧凑布局。

## 星轨与氛围灯

舞台的星轨是静止的玻璃刻纹，文字区域淡化、角色雕刻周围避让。强调色流光沿右侧空玻璃里的部分轨迹前进，随窗口尺寸选择可用路径；原来的舞台下沿短线已移除。流光是氛围装饰，不代表音量或频谱，关闭音乐图案后仍可保留。

流光采用更长的流星尾迹，从细暗尾端连续过渡到明亮圆头，长度随轨道适配、最长 320px。较宽舞台最多开放 8 条可用轨道，包含更多外侧刻纹；小窗口自动减少，文字、封面、音乐图案和角色雕刻周围仍留有空隙。

播放且未静音时流动；暂停、缓冲、静音或零音量时停住并淡化，恢复播放后继续。窗口隐藏或离开收藏页时暂停；减少动效时为静止光迹，系统高对比度下隐藏。播放条上沿短线保留，并采用相同的亮暗条件。

所选环上的可见分段和边缘已补齐，没有小碎片例外。不可见行程加速通过，可见段平顺缓慢；流光恢复适量混白，头部有小范围辉光，与频谱顶部协调。完整周期随可见轨段多少而变化，不必担心短暂消失就是漏光。

## 迷你音量

鼠标移到迷你卡片，或用键盘聚焦卡片按钮后，右上方会显示音量入口。点开后可以拖动滑块、静音或用方向键调整；数字显示当前百分比。主窗口与迷你窗口共用音量。

按 Escape、点收起键、再次点入口，或点卡片其他位置即可收起。面板留在卡片内部，歌词、封面和进度线保留。拖动或双击音量控件不会拖动窗口或展开主窗口。

## MV 联动

继续支持关联已有的 MKV MV，再交给 PotPlayer 播放。仅保存文件位置，不复制视频。成功启动后暂停音乐，关闭视频后由你手动恢复；移除关联不会删除视频。详见包内《MV使用说明.md》。

## 使用提示

星轨根据空余玻璃区域选择路径，所以切换专辑、字号或窗口尺寸后，流光数量和位置可能变化。较大的界面字号搭配临界窗口宽度时，音乐图案会缩小，优先保证文字可读。三种主题沿用各自的亮度与玻璃材质；纪念铭牌里的 V1.0 刻字保留为最初合作纪念。
