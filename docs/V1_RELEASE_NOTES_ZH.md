# CD 播放器 V1.0.0 · 版本说明

2026-10-08，应用版本 1.0.0，共享接口 0.4.0。以用户已验收的 core.28 为功能与最终界面基线。

## 本次发布

- 本地逐曲 FLAC/WAV/MP3 收藏、播放、队列排序、主/迷你双窗与托盘。
- 后台上一首、下一首、播放/暂停快捷键；启动恢复、目录关联、资料备份和从收藏移除。
- 逐字段资料编辑与保护、在线资料候选；多来源歌词候选、双语预览、编辑/打轴/草稿导入、偏移与冲突处理。
- 三套主题、水晶控制按钮、唱片图标，以及可关闭的两处合作纪念铭牌。

新收藏默认灰黑与 #DB7A3D，已有收藏与用户强调色保留。此次从 core.28 升为正式应用编号，在线请求标识同步为 CDPlayer/1.0.0；不改共享契约、界面、默认值、数据规则、迁移或依赖版本。

交付 Windows x64 便携包、源码存档、使用说明、第三方声明与文件哈希。便携包需系统已有 WebView2。安装器仍是另行验收的草案，不包含在本次正式交付；未签名、无自动更新。

用户已确认主要功能、后台草稿退出、耳机/输出恢复、休眠唤醒及最终铭牌试用通过。正式与人工验证范围见 TESTING.md；历史原始截图和交接资料保留在私人开发存档。

公开源码采用 MIT，字体与依赖保留各自许可证，纪念素材另列声明。个人邮箱改为项目网址，功能、界面与收藏数据不变。合影收录于 README；私人原稿保留在本地存档。
