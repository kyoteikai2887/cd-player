# CD 播放器 V1.2.1 · 正式版本说明

2026-10-13，用户最终验收并冻结。共享接口 0.6.0。

- 主舞台音乐点阵随真实音乐起落，连线取自 Transformer 注意力图的设计语言；文字和图案随窗口尺寸协调摆放。
- 星轨保持玻璃蚀刻，流光具有连续长尾、适量混白和小范围头部辉光；补齐所选环的可用分段及边缘，取消碎片例外，不可见路程加速通过。
- 迷你窗口按需展开音量与静音控件，与主窗口同步。
- 底部播放条整面专辑色光；专辑可关联已有 MKV MV，通过 PotPlayer 观看，只记录文件位置、不复制视频。

先从旧版托盘“退出”，再解压整个包并运行 CD播放器.exe。保留 runtime、web、licenses，系统需已有 Microsoft Edge WebView2 Runtime。已有收藏、设置和 MV 关联沿用。详细使用见 V1.2新增功能说明.md、MV使用说明.md；验证见 V1.2.1检查说明.md。
