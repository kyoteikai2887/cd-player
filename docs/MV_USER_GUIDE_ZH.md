# 专辑附带影像与 PotPlayer

本功能关联已经导出的 MKV 视频，不负责读取或转换 DVD。

1. 打开对应专辑，点“更多 → 关联 MV…”，选择 MKV。
2. 视频出现在曲目表下方的“附带影像”；点击该行交给 PotPlayer 播放。
3. 开始观看后音乐暂停，看完后手动按播放继续。

如果没有找到 PotPlayer，进入设置的“MV 播放”，选择“自动查找”或“选择程序…”。手动选择 PotPlayerMini64.exe（或其它 PotPlayer 主程序），适用于便携版。

视频的行菜单可以改显示名称、重新关联文件、移除关联。改名不改变磁盘文件名，移除不删除文件。移动视频文件后使用“重新关联文件…”指定新位置。

本功能只保存路径；视频仍占用原来的一份空间，不会在播放器资料库里再复制一份。MV 不加入音乐播放队列，也不计入专辑曲目数或音频时长。
