# V1.0 进度与收尾

2026-10-08，应用正式编号 1.0.0，契约 0.4.0；以用户最终确认的 core.28 为界面与功能基线。

V1.0 的功能开发与用户试用已完成：本地导入/目录关联、播放/队列/后台快捷键、双窗/托盘、歌词编辑/打轴/草稿导入/冲突、资料保护、备份/移除/启动恢复、在线资料及多源歌词候选/译文。纪念主题、水晶控件、唱片图标和铭牌已验收。歌词覆盖仍取决于来源，使用候选需要确认。

用户 2026-10-05 报告托盘草稿退出、耳机/输出恢复、播放与暂停休眠唤醒均通过；2026-10-08 报告成品试用完全没问题，授权正式封包。未提供的物理显示器组合和系统高对比度实机细节不补记为通过。

本次重新核对 1.0.0 构建、便携文件、许可证与公开源码，结果见 TESTING.md。core.28 的 38 张原生截图与图片/设置重启检查、core.21 的小时后台和 core.22 的隔离安装结果保留原归属，不标成此次重新执行。

功能与人工试用已收尾。当前准备 MIT 公开源码、Windows x64 便携版与 GitHub Release；最终上传待用户授权。安装器、签名、自动更新与其他平台支持留待后续版本。
