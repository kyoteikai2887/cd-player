## 完整周期、红笔区域与连续缩放

Windows Edge 按实际渲染的玻璃遮罩生成目标点，并在完整周期内检查真实 CSS 动画位置与 SVG 头部：66,513 / 66,513 个目标点被头部扫到，仅被尾部扫过 0，始终不亮 0。本轮新增目标 9,035 / 9,035，最小归一化峰值 0.999。没有小碎片例外。Windows 与 Claude 报告的点数相差 12，为字体和栅格渲染差异；本机目标全部通过。

2100 × 900 的 A–E 同类红笔区域，头部通过数依次为 44 / 44、40 / 40、76 / 76、40 / 40、60 / 60。它们覆盖顶边、右侧小环、底边及图案下方遗漏。原截图是裁切图、原始窗口尺寸未知，复核使用同类布局，不能宣称逐像素还原原截图。

另用 Claude 修复前写好的 Codex 裁切诊断进行独立完整周期采样：5 种布局、每周期 1,201 个时刻，1,080 / 1,080 个边界样本被头部覆盖；裁切外目标、弱端点及始终不亮均为 0。该诊断独立于流光实现，使用估算的可见几何和实际 SVG 变换，是对栅格检查的补充。

同一个舞台连续经历 11 次窗口尺寸变化，包含 1.3 倍字体和长日文标题；与对应尺寸的新舞台比较路径、裁切、尾迹、辉光、节奏与引用，全部一致，没有通过重新挂载绕过缩放问题。

完整周期约 10.6–40.3 秒；最长不可见间隔 1.382 秒，可见段最大步进 1.5 px，速度差约 0.01%。可见轨段多时整个周期仍较长，加速的是不可见路程。

## 配色、辉光与实际播放

三主题恢复适量混白；灰黑头部沿用频谱连线／峰值色，纸白与蓝主题额外少量混白。尾部以强调色为基底，头部采用小范围径向辉光，没有加入全屏模糊滤镜。457 个足够可见的头部颜色样本中最大色相偏离约 6.7°，自选强调色跟随验证通过。

已查看 Windows Edge 三主题真彩色截图，以及原生 WebView2 解码音频下的灰黑、纸白舞台。原生检查使用合成封面与测试 WAV，验证低频／高频落入不同频段、播放状态、静音、隐藏、减少动效、高对比度和迷你音量同步等。三套原生流程本轮首次均通过，正常退出，没有读取真实音乐库或强制终止用户程序。

## 验证边界

完整覆盖指被选为流光的环上可用轨段，不表示每一条静止刻纹都必须发光。目标由实际遮罩大于 8/255 的点生成，另列文字／封面及纪念图案墨迹的明确安全间隙；没有以端点长度排除小碎片。头部峰值是共享玻璃遮罩之前的归一化光强，最终图像仍保留原背景淡化；落在实际内容轮廓中的轨道按设计避让。

测试在本机 Windows Edge / WebView2 完成，强制配色为模拟检查。没有重做长时间物理睡眠唤醒、多显示器混合缩放、Windows 10 或缺少 WebView2 的干净系统验证。旧引擎不支持 CSS linear() 时仍走完整环，但隐藏路程退回匀速；该旧引擎未实测。
