# Windows 人工验收指南

本项目已在用户设备试用，托盘退出取消/草稿保留、耳机/输出恢复、播放/暂停休眠唤醒均报告通过。下面是复查指南，不表示所有机器都已覆盖。

- 托盘退出：在歌词编辑器修改草稿，选择托盘退出，再取消；窗口、草稿与播放状态应保留。确认退出后下次打开应正常释放/获取资料锁。
- 音频设备：播放中切换或重新连接耳机，确认能继续播放或明确提示重试，不应重复播放、换曲或卡住控件。
- 休眠：分别在播放与暂停状态休眠并唤醒，界面恢复；暂停不会自行播放。
- 显示：主/迷你窗口跨显示器移动，100%、125%、150%、200% 缩放下检查文字、水晶边缘与歌词高度。迷你歌词增高应保持在工作区。
- 外观：三主题、最高和关闭玻璃强度、Windows 高对比度分别查看；高对比度下纪念图隐藏、文字保留。
- 升级：退出旧便携版后打开新目录，收藏和设置应保留。不要只移动 exe，不要在运行时覆盖资料文件。

无对应硬件或环境时记为“未覆盖”。日志只保存在本机；公开反馈前清理其中的曲名、路径及个人信息。
