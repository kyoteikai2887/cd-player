# CD 播放器 V1.0.0 · 使用说明

Windows x64 便携版，界面与功能沿用已验收的 core.28。首次使用的默认主题是灰黑底与窑烧陶土橙 #DB7A3D，已有收藏保留原设置。

## 打开与升级

先从旧版托盘菜单选择“退出”，解压整个 ZIP，再双击 CD播放器.exe。请保留同目录的 runtime、web、licenses，不单独移动 exe。系统需已有 Microsoft Edge WebView2 Runtime；此便携包不安装该运行环境。

沿用相同应用标识 local.cdplayer.v1，收藏、歌词、备份和设置存放在 %APPDATA%\local.cdplayer.v1，换便携目录无需重建收藏。关闭窗口会收到托盘；真正结束程序请用托盘“退出”。有未保存编辑时会询问，取消退出会保留草稿。

## 导入与播放

选择“导入文件夹”，导入抓轨目录里的逐曲 FLAC、WAV 或 MP3。原音乐、LRC、EAC 日志和 CUE 保持原样；EAC 日志帮助识别碟片和曲号，播放器不会重新执行 AccurateRip。整碟镜像加复杂 CUE 不是本版的完整播放入口。

在收藏中打开专辑，点击播放，或选择某首。播放队列支持拖动、键盘和菜单排序。主窗口与迷你窗口共用一个播放引擎；迷你歌词开关只在同步歌词时显示当前行。移动音乐后用目录重新关联恢复路径，详见“目录恢复说明.md”。

“从收藏移除”只清理播放器中的记录和对应队列项，保留原音乐文件；正在播放该专辑时会停止。移除前有资料备份，相关未保存草稿会在确认框说明，取消或失败保留草稿。

## 后台快捷键

| 功能 | 快捷键 |
|---|---|
| 上一首 | Ctrl + Alt + ← |
| 下一首 | Ctrl + Alt + → |
| 播放 / 暂停 | Ctrl + Alt + P |

窗口隐藏或收到托盘后仍可用。已播放超过约三秒时，“上一首”先回到本首开头，再按切到前一首。组合被其他程序占用时不抢占，托盘“快捷键说明”显示实际状态。

窗口内空格播放/暂停，Ctrl+F 搜索。编辑器 Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做；打轴时空格按下即记时间。队列 Alt+↑/↓ 调整顺序。

## 资料与歌词

在线资料从候选中逐字段确认，手动改过的字段受保护。歌词候选来自 LRCLIB、QQ 音乐、网易云音乐和酷狗音乐；需要联网，来源缺失或服务失败时可导入本地 LRC。曲名相同不保证演唱版本相同，请预览并核对时长、署名和内容。

已有歌词时，在线候选导入编辑草稿，只有明确保存才落库。来源带译文可切换双语预览，导入后展开译文列；不自动翻译。支持编辑、打轴、偏移、锁定和冲突比较。详细请求与缓存规则见“在线说明.md”。

## 外观、备份与故障记录

设置可切纸白、阿根廷蓝、灰黑、自选强调色与玻璃强度，并关闭纪念铭牌。关闭透明或高对比度时使用对应回退。纪念铭牌是装饰，不影响操作。

保存资料前按既有规则创建本地自动备份。备份不复制原音乐和封面缓存实体，搬迁时一起保留音乐与应用资料目录。不要在程序运行时手动替换 library.json；恢复方式见 BACKUP_ZH.md。

遇到问题，先记下时间与操作，从托盘退出后保留应用资料目录 logs 中的 diagnostics*.ndjson，再参考“故障记录说明.md”和“启动修复说明.md”。日志在本机保存，不自动上传。

此版未签名，未提供自动更新。已在本机 Windows 11 与用户设备试用通过；Windows 10、其他硬件/显示条件和缺少 WebView2 的干净环境未全部验证。流式播放不承诺逐采样无缝，在线来源不承诺每首歌词都命中。
